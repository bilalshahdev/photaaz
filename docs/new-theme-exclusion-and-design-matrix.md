# Photaaz: six-new-theme exclusion and design matrix

## Existing catalogue — exclusion reference

| Existing theme | Territory that new themes must not reuse                                              |
| -------------- | ------------------------------------------------------------------------------------- |
| Lumen          | Calm light canvas, conventional horizontal header, image-first grid, restrained cards |
| Archive        | Warm magazine hierarchy, asymmetric editorial split, serif-led stories                |
| Noir           | Dark full-bleed cinema, overlay navigation, dramatic oversized hero                   |
| Contact Sheet  | Permanent left sidebar, dense modular archive, geometric grid                         |
| Atelier        | Black/gold boutique luxury, centered brand with split nav, fashion spacing            |
| Monogram       | Black-and-white fine-art gallery, restrained monochrome typography                    |
| Horizon        | Panoramic landscape canvas, atmospheric full-width pacing, rounded spatial panels     |
| Velvet         | Burgundy fashion collage, aggressive display type, red-accented archive language      |

## Pairwise rejection check

- No new theme uses Contact Sheet's permanent desktop sidebar.
- No new theme uses Noir/Horizon full-screen hero followed by a conventional card grid.
- No new theme uses Archive's warm magazine split or Atelier's centered-brand split navigation.
- No new theme relies on monochrome, burgundy, gold, or color replacement as its differentiator.
- Relay is sequence-driven; Fieldbook is annotation-driven; Kaleido is tile/portal-driven; Proscenium is act/stage-driven; Cartograph is route/spatial-driven; Vitrine is room/exhibition-driven.
- Each identity requires its own header, mobile navigation, home renderer, internal-page shell, contact composition, footer, and scoped content presentation.
